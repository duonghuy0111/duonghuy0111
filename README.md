## 🚀 Featured Projects

### 🤖 AI Learning Assistant — RAG & LLM

An AI-powered learning assistant designed for document-grounded question answering and AI-assisted learning.

**Highlights:**
- RAG pipeline using embeddings and vector search
- PostgreSQL + pgvector for semantic retrieval
- LLM-based reranking for relevant context selection
- Grounded answers with source citations
- PDF, image, and video document processing
- AI-generated quizzes and essay grading
- Structured LLM output validation with Zod
- JWT authentication and API validation
- Automated testing with Jest and Supertest
- Dockerized deployment

**Tech:** TypeScript · NestJS · PostgreSQL · pgvector · OpenAI API · Prisma · React · Docker

🔗 **Repository:** [ai-hoc-tap](https://github.com/duonghuy0111/ai-hoc-tap)

### 📚 Smart Library — Library Management System

A library management system developed with a layered backend architecture.

**Highlights:**
- REST APIs for users, documents, categories, borrowing, reviews, and transactions
- JWT authentication and Spring Security
- Controller–Service–Repository architecture
- Hibernate/JPA with MySQL
- VNPay payment integration
- Cloudinary image management
- Statistical APIs for system usage and revenue
- Swagger/OpenAPI documentation

**Tech:** Java · Spring · Spring Security · Hibernate · MySQL · JWT · VNPay · Cloudinary · React

🔗 **Repository:** [Smart-Library](https://github.com/duonghuy0111/Smart-Library)
